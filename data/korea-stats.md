# Korea in numbers: reference statistics for the games

Real-world figures for tuning the Suneung Simulator (and any later Korea-based game). Every row names the organization that published the number and the page it was read from. See `data/README.md` for the format, the status tags and how to add rows.

**Status tags (in Notes):**
- **official**: read on a government or public-agency page (korea.kr, moe.go.kr, kostat.go.kr / mods.go.kr, mogef.go.kr, kdca.go.kr, molit.go.kr, KEDI, KICE, KoROAD, NCC, Dhlottery). The figures were read from the page text returned by the search tool; attachments (xlsx/hwp/pdf tables) were not opened unless noted.
- **unverified**: seen only in a news report or secondary site that cites an official release. Use with care and replace with the primary figure when found.
- **calc**: derived by us from official figures; the formula is in Notes.

Currency: 만원 = ₩10,000, 억 = ₩100,000,000. Statistics Korea renamed itself 국가데이터처 (Ministry of Data and Statistics, mods.go.kr) in 2025; older pages are on kostat.go.kr.
