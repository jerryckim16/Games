# Korea in numbers: adult life

Official Korean statistics for taking the Suneung Simulator (and later Korea-based games) past school: work, money, housing, family, health and daily life from the twenties to old age. Same format and status tags as `../korea-stats.md` (see `../README.md`); these files extend it rather than repeat it, and say so where a row updates one there. Each file ends with **Game ideas** (how its figures could drive mechanics) and **Gaps**.

Retrieved 2026-11-10; refreshed 2026-11-11 (October 2026 고용동향, the August 2026 비임금근로 부가조사, September 2026 migration, the 2025 이주배경인구 register census, the 2026 교육기본통계 and Bank of Korea ECOS series). Most figures were read from the released files themselves (xlsx, hwpx, hwp, pdf attachments on mods.go.kr, korea.kr, moel.go.kr, kdca.go.kr, mcst.go.kr, nec.go.kr, index.go.kr) or official APIs (OECD SDMX).

**Reaching the sources from a cloud session.** mods.go.kr, korea.kr, moel.go.kr, mohw.go.kr and index.go.kr work through curl but drop connections now and then (retry). kosis.kr fills tables by script and blocks automated table requests; nps.or.kr is script-built too. nts.go.kr, law.go.kr (for WebFetch), molit.go.kr, mma.go.kr, immigration.go.kr, police.go.kr, kostat.go.kr, cancer.go.kr, nhis.or.kr and hira.or.kr reset or time out; oecd.org returns 403 (its SDMX API works). The Bank of Korea's ECOS open API (ecos.bok.or.kr/api) answers with its public `sample` key (10 rows a call). academyinfo.go.kr resets connections. Rows that could only be read from news or search text are tagged unverified.

**Worth knowing for a region model:** from mid-2026 several releases report Gwangju and South Jeolla together (전남광주통합특별시), which the game's places already follow.
