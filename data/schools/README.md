# The national school list

`korea-schools-2026-09.csv` is every operating elementary, middle and high school in Korea: 12,004 schools (6,286 elementary, 3,316 middle, 2,402 high) with ID, name, level, founding date, national/public/private, main or branch campus, addresses, office of education, latitude and longitude.

- **Source:** 한국교육시설안전원 (Korea Educational Facilities Safety Agency), "한국교육시설안전원_초중등학교위치_20260920", on the public data portal: https://www.data.go.kr/data/15159184/fileData.do
- **Data date:** 2026-09-20 (registered 2026-09-20, revised 2026-10-01). Downloaded 2026-10-29.
- **License:** 이용허락범위 제한 없음 (no usage restrictions), free.
- **Updates:** twice a year; the next release is due 2027-03-31. Replace the file and update the counts in `../schools.md` when it comes out. Checked 2026-11-04: the page still offers only `초중등학교위치_20260920` (revised 2026-10-01), so this file is current.
- **Format:** UTF-8 with BOM, comma-separated, the provider's own Korean column names, unchanged.
- **Boys', girls' and coed schools:** `korea-school-coed-2026-11.csv` gives each middle and high school in the list above its 남녀공학구분 (남 boys only, 여 girls only, 남여공학 coed), by 학교ID. It was fetched on 2026-11-10 from NEIS `schoolInfo` (`COEDU_SC_NM`) by querying each school's exact name and matching the road address's district; 5,691 of 5,718 matched (column 근거 = neis). The other 27, where same-named schools could not be told apart, are classified from the name (여자/여중/여고 → girls, 남자 → boys, else coed; 근거 = name). Middle schools: 2,681 coed, 324 boys, 311 girls; high schools: 1,614 coed, 387 boys, 401 girls. The column 고교유형 is NEIS's high-school type (`HS_SC_NM`) for the high schools that matched: 일반고 1,635, 특성화고 487, 특목고 159, 자율고 112 (39 of them private: the regional and nationwide 자사고). Elementary schools are coed and not listed. The game's `tools/build_places.py` reads it so that no player is placed in a school of the other sex.
- **Not in this file:** kindergartens, special schools (특수학교), alternative schools, and high-school type (일반고, 특목고, 특성화고, 자율고). NEIS (open.neis.go.kr, `schoolInfo` → `HS_SC_NM`) has the high-school type, but without an API key it returns only 5 rows per query (and ignores `pIndex`). On 2026-11-04 every high school in this file was classified by querying NEIS once per school by exact `SCHUL_NM` plus `ATPT_OFCDC_SC_CODE` (2,396 of 2,402 matched); the results are the named lists in `../schools.md` §3. NEIS lists 전남광주통합특별시교육청 schools as 전남광주통합특별시교육청(전남) (143 high schools) or (광주) (68); they were queried with the old codes Q10 and F10. With a free NEIS key the list could be fetched in a few calls instead.
